- Audio channels: mono, stereo, or keep original
- Trim: set start/end time (video and audio)
- Remove audio: option to mute video entirely

─────────────────────────────────────────────
COMMON ERRORS & TROUBLESHOOTING
─────────────────────────────────────────────
1. “File extension does not match content type”
   → You renamed a file to a different extension. Restore the original extension or convert with a tool that matches the actual file type.

2. “Compression did not produce an output file”
   → The file might already be as small as possible, or the settings prevented a valid output. Try a milder quality setting.

3. “Total file size exceeds 100 MB”
   → The combined size of all files in one batch is over 100 MB. Split them into multiple requests.

4. “No extractable text found”
   → The PDF is likely image‑only (scanned pages). Our summarizer works with text‑based PDFs.

5. “PDF processing timed out”
   → The PDF may be corrupted or too complex. Try a different file.

6. “Invalid settings JSON”
   → The options you selected in the frontend became corrupted. Refresh the page and try again.
