COMMON ERRORS & TROUBLESHOOTING
─────────────────────────────────────────────
1. "File extension does not match content type"
   → The file was renamed to a wrong extension. Restore the original extension or convert with a matching tool.

2. "Compression did not produce an output file"
   → The file may already be at its minimum size, or the settings prevented a valid output. Try a milder quality setting.

3. "Total file size exceeds 100 MB"
   → The combined size of all files in one batch exceeds the limit. Split them into separate requests.

4. "No extractable text found"
   → The PDF is likely image‑only (scanned). Our summarizer requires text‑based PDFs.

5. "PDF processing timed out"
   → The PDF may be corrupted or too complex. Try a different file.

6. "Invalid settings JSON"
   → The options selected in the frontend became corrupted. Refresh the page and try again.
