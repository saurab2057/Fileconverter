SERVICES OFFERED
─────────────────────────────────────────────

1. File Conversion
   - Image: PNG ↔ JPG, PNG → SVG, PDF → JPG, plus WebP and GIF output
   - Video: MP4, WebM, MKV, MOV, AVI cross‑conversion (H.264 encoding)

2. File Compression
   - JPEG, PNG, WebP, GIF – lossy optimization with adjustable quality
   - Video – H.264 CRF-based compression (quality levels: high/medium/low)
   - Audio – bitrate reduction (192kbps / 128kbps / 96kbps)
   - All compression preserves original resolution/format unless you choose otherwise

3. AI Summarization
   - Two input methods: upload a PDF (max 2 MB, only the first 5 pages are read) OR paste text directly into the summarizer
   - The input size for text ranges from 50-512 words count
   - PDF must be text-based; scanned/image-only PDFs are not supported (no OCR)
   - The system generates a concise plain‑text summary

4. Batch Processing
   - Upload up to 5 files at once
   - All files are processed in parallel
   - You receive individual download links for each output
   - Applies to conversion/compression only — the AI Summarizer processes one PDF or one text input at a time, not batches

─────────────────────────────────────────────
COMMON ERRORS & TROUBLESHOOTING
─────────────────────────────────────────────
1. "File extension does not match content type"
   → You renamed a file to a different extension. Restore the original extension or convert with a tool that matches the actual file type.

2. "Compression did not produce an output file"
   → The file might already be as small as possible, or the settings prevented a valid output. Try a milder quality setting.

3. "Total file size exceeds 100 MB"
   → The combined size of all files in one batch is over 100 MB. Split them into multiple requests.

4. "No extractable text found"
   → The PDF is likely image‑only (scanned pages). Our summarizer works with text‑based PDFs only.

5. "PDF processing timed out"
   → The PDF may be corrupted or too complex. Try a different file.

6. "Invalid settings JSON"
   → The options you selected in the frontend became corrupted. Refresh the page and try again.
