================================================================================
                    KEY FILE RESPONSIBILITIES
================================================================================

ENTRY POINTS:
├── index.js           → Starts server, connects to DB, listens on port
└── app.js             → Configures Express, middleware, routes

AUTHENTICATION FLOW:
├── authController.js  → Handles login/signup logic
├── passwordController.js → Handles password reset flow
├── sessionController.js  → Handles token refresh & session management
├── authMiddleware.js  → Verifies JWT on protected routes
└── Session.js         → Stores refresh tokens (separate collection)

FILE HANDLING:
├── conversionController.js → CloudConvert API integration
├── fileUpload.js      → Multer configuration
├── cloudinary.cjs     → Profile picture upload
├── pdfProcessor.js    → PDF text extraction
└── fileSecurity.js    → MIME type validation

AI FEATURES:
├── chatbotController.js    → HuggingFace chat API
├── summarizerController.js → HuggingFace summarization API
└── aiSecurity.js           → Prompt injection protection

ADMIN & AUDIT:
├── adminController.js → Dashboard, user management
├── auditLogger.js     → Log admin actions
└── AuditLog.js        → Immutable audit records

SECURITY:
├── security.js        → CORS, Helmet, headers
├── rateLimiter.js     → Rate limiting (7 types)
├── validation.js      → Input validation rules
├── recaptchaMiddleware.js → Bot protection
└── authSecurity.js    → IP hashing, token checks
